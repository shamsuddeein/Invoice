# Brand assets

Drop the official AUSAD logo files here. The app loads them by these exact names:

- **`ausad-logo.png`** — full horizontal lockup (mark + "AUSAD" + "Innovation Limited").
  Used on the login screen, the app header / sidebar, and as the default logo on
  invoices & receipts (a logo uploaded in Settings still overrides it).

- **`ausad-mark.png`** — *(optional)* icon-only mark — the symbol with no text. Used for
  the browser tab icon (favicon) and the small square badge in the sidebar / mobile
  header. If it's missing, the full lockup is used in those spots too.

PNG with a transparent background is ideal. Replacing a file here updates the logo
everywhere — nothing else to change.
